## Overview

![screenshot](./assets/design/preview.png)

I built a product preview card component that showcases a perfume product with an elegant and responsive design. The project features a two-column layout on desktop with product image and details, transforming into a single-column mobile-friendly card. It includes product information, pricing, and a call-to-action button following e-commerce design patterns.

### What I learned

-   **Responsive Image Handling**: Implementing the picture element with source tags to serve different images optimized for mobile and desktop viewports.
-   **Semantic HTML Structure**: Building accessible product cards with proper heading hierarchy and semantic markup for better SEO and screen reader support.
-   **Mobile-First Responsive Strategy**: Developing styles from mobile breakpoints upward, resulting in cleaner CSS and better performance on smaller devices.

## Built with

-   HTML5 Semantic Structure
-   CSS3 Mobile-First Design
-   CSS Custom Properties (Variables)
-   Adaptive Typography (clamp, rem)

## Features

-   **Mobile-First Responsive Design**: Built starting from mobile breakpoints and progressively enhanced for tablet and desktop experiences.
-   **Adaptive Layout System**: Transforms from a single-column mobile card to an elegant two-column desktop layout using Flexbox.
-   **Interactive Elements**: Hover states and visual feedback on interactive components for enhanced user experience.

This [Frontend Mentor](https://www.frontendmentor.io/challenges) project strengthened my understanding of responsive design patterns, semantic HTML, and modern CSS layout techniques essential for building professional e-commerce interfaces.
